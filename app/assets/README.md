# Assets

Coloca aquí los siguientes archivos:

- `icon.png` - Icono de la app (1024x1024)
- `splash.png` - Splash screen (1284x2778)
- `adaptive-icon.png` - Icono adaptivo Android (1024x1024)
- `notification-icon.png` - Icono para notificaciones (96x96, solo Android)
- `notification.wav` - Sonido de notificación (opcional)

Puedes generar estos assets usando herramientas como:
- https://easyappicon.com/
- https://appicon.co/
- Figma / Adobe XD
